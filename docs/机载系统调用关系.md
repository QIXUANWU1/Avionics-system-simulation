# 机载系统怎样交换数据

## 一、从测量到显示

一个屏幕可以同时显示多个系统的结果。软件按来源分别检查这些结果的有效性，最后再把它们排到同一页上。主飞行页上的空速、姿态和地速因此可以独立更新。

| 功能 | 上游与下游 | 一路数据失效时 |
|---|---|---|
| 姿态 | 主、备惯性采样 → 姿态选择 → 姿态检查 → 主飞行显示。主操纵计算也读通过检查的姿态。 | 惯性数据有问题时，地平线和姿态状态可以单独失效。空速仍读自己的数据源。 |
| 指示空速 | 合成大气数据采样 → 空速与高度字 → 解码 → 空速带 | 大气数据失效时清空空速带，姿态和有独立来源的导航数据仍可用。 |
| 气压高度与垂直速度 | 空速与高度字 → 解出的气压高度 → 垂直速度计算 → 高度带和升降速度 | GNSS 丢失时仍可更新。当前台架用气压高度变化量计算垂直速度。 |
| GNSS 导航 | 合成运动 → GNSS 航迹、地速、高度采样 → 导航数据和主飞行页辅助读数。另一支 GNSS 平面位置送航点和航段解算。 | 气压高度数据失效时，GNSS 航迹和地速仍可更新。GNSS 定位失效时，航点距离与横偏清空。 |
| 高度源对照 | 气压高度（ft）和 GNSS 高度（m）统一换算后做差 | 缺少任一来源时不给出源差。台架仅用差值提示读数需要检查。 |

FAA 手册第 8 章分别讲解皮托静压仪表、电子飞行显示、空气数据计算和姿态航向参考。按这一分工，本台架把空速、高度、惯性姿态和卫星导航分别建模。[FAA PHAK 第 8 章](https://www.faa.gov/regulationspolicies/handbooksmanuals/aviation/phak/chapter-8-flight-instruments)

## 二、机电状态怎样产生

| 功能 | 上游与下游 | 一路数据失效时 |
|---|---|---|
| 液压 | 台架主供压读发动机状态，备用电泵读直流供电。压力和当前来源由液压状态服务统一输出。 | 直流状态缺失时仍可接收有效的发动机驱动供压。主源不可用且直流供电有效时，台架使用备用供压。 |
| 起落架 | 拨杆提出命令，液压驱动机构，机构提供收上和放下的限位，显示按限位判断位置。承重开关参与收上许可。 | 压力数据失效时，已有的限位读数仍可显示。上下限位同时有效属于矛盾，位置显示失效。 |
| 承重与地面液压刹车 | 台架用离模拟跑道的高度与起落架机构状态生成承重开关。刹车状态再读承重、放下位置和液压状态。 | 放下起落架的飞机仍可能在空中。承重有效、液压数据缺失时，页面可单独显示液压数据缺失。 |

FAA 对液压泵给出发动机驱动与电驱动等常见实现。主、备供压的组合是台架选用的结构。可收放起落架的限位指示和承重开关分别表达位置和接地条件。第 12 章的第 12-12 至 12-14 页展示了这两类装置，并说明接地时承重开关用于阻止误收上。[FAA PHAK 第 7 章](https://www.faa.gov/regulationspolicies/handbooksmanuals/aviation/phak/chapter-7-aircraft-systems) · [FAA Airplane Flying Handbook 第 12 章](https://www.faa.gov/sites/faa.gov/files/regulations_policies/handbooks_manuals/aviation/airplane_handbook/13_afh_ch12.pdf)

## 三、一次更新经过哪些软件

1. 采集任务发布带来源、序号、时间和有效标志的样本。
2. 消费服务按配置选择输入，检查每项数据的年龄，再计算自己的结果。
3. 显示容器从只读显示主题取得结果。C 负责计算和画面，Python 提供页面。缺失值显示为横线或文字提示。
4. 本地离线检查可直接给服务构造正常与故障输入，确认只有依赖该输入的读数受到影响。

模拟轨迹把压差、空速和飞机运动简化成有单位的数值。模拟的空速和高度仍共用一份采样字包。单项仪表之间的独立性以不同上游来源为界。
